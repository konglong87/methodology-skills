二、Codex++ 基础认知（是什么、解决什么问题）
1. 工具简介
Codex++ 是一款
开源免费的 Codex 桌面版增强启动器
，安全无捆绑。
核心运行逻辑：仅在启动Codex时动态加载增强能力，
不修改原版程序文件、不篡改系统配置
，原版Codex升级后仍可正常使用。
2. 原版Codex三大核心痛点
日常使用官方客户端时，会遇到以下限制，也是Codex++的核心价值：
接口登录限制：使用密钥登录后，顶部「插件」按钮会被锁定置灰，无法使用
会话管理鸡肋：仅支持「归档」会话，无法彻底删除，测试会话越积越多
API配置繁琐：想要切换自定义接口，需要手动修改系统隐藏配置文件，版本更新后配置直接失效

五、核心功能使用（分层学习：必学/选学/拓展）
🔰 第一部分：零基础必学（所有用户掌握）
5.1 解锁插件功能（最常用核心功能）
操作步骤
双击桌面 
Codex++
 图标启动客户端，等待程序完全加载完成
查看顶部导航栏，原本灰色的「插件」按钮已恢复可点击状态，直接正常使用即可
极简原理
原版Codex做了权限区分：账号登录允许使用插件，密钥登录直接屏蔽插件入口。Codex++ 在启动阶段自动解除界面权限限制，无需切换登录方式。
5.2 永久删除会话（清理冗余记录）
操作步骤
正常用 Codex++ 启动软件，左侧为会话列表
将鼠标
悬停
在任意一条会话上（无需点击），会话右侧会出现
红色删除图标
点击删除图标，会话会被
永久清除
（区别于原版仅归档）
5.3 对话导出为 Markdown（笔记/存档）
操作步骤
打开需要保存的对话内容
点击页面右上角「导出」按钮，选择 
Markdown
 格式
文件会自动保存到本地电脑，可用于整理学习笔记、工作对话记录。
⚙️ 第二部分：初级进阶选学（有自定义接口需求再学习）
前置名词解释（零基础必看）
API Key
：可理解为对接AI服务的「身份钥匙」，格式大多以 
sk-
 开头，用于身份校验
Base URL
：AI服务的「网络地址/门牌号」，用来指定程序连接哪一台服务节点
中转API
：第三方转接服务，作用是替换Codex默认官方接口，提升稳定性、适配私有服务
5.4 配置自定义中转API
适用场景
已登录账号，但不想使用官方默认接口，需要切换为自有/第三方中转服务。
操作步骤
双击桌面 
Codex++ Manager
 打开管理工具
左侧菜单栏选择「运行模式」→「API中转设置」
填写两项关键信息：
Base URL：填入你的中转服务网络地址
API Key：填入对应服务的身份密钥
填写完成后点击「一键应用」，配置自动保存
⚠️ 关键操作提醒
配置完成后
必须完全关闭Codex所有窗口，重新使用 Codex++ 启动
，新API配置才会生效。
极简原理
原版Codex将接口配置存于隐藏文件，手动修改易出错、更新易重置；Codex++ 提供可视化面板，配置持久化存储，不受原版程序升级影响。
🧩 第三部分：拓展小功能（按需了解，非必备）
5.5 Timeline 历史视图
可查看单条会话的完整编辑记录，支持回溯历史对话版本，适合需要复盘内容的场景。
5.6 项目移动
支持在客户端内直接调整项目文件夹位置，无需手动修改本地文件路径。
5.7 用户脚本
类似浏览器插件功能，可自定义Codex界面样式、增加小众辅助功能，属于高阶玩法，新手可暂时忽略。
六、Codex++ Manager 管理工具详解
该工具主要用于
状态自检、配置管理、故障修复
，日常使用频率较低。
首页「概览」：自动扫描原版Codex安装路径、运行状态、版本信息，显示「正常/已找到」代表无异常
异常处理：若出现红色告警项，直接点击对应「修复」按钮即可自动处理
右上角「重启Codex」：一键重启客户端并重新加载所有增强功能，功能异常时优先使用此按钮。

八、常见问题&排错指南（高频踩坑汇总）
macOS 打开提示「应用已损坏，无法打开」
解决：系统设置 → 隐私与安全，下滑找到Codex++，点击「仍要打开」放行。
启动后插件依旧是灰色，没有解锁
排查：① 确认使用 
Codex++
 图标启动，而非原版图标；② 关闭所有窗口后重新启动；③ 检查Codex++版本是否为最新版。
中转API配置完成后不生效
排查：① 核对 Base URL、API Key 字符是否输入错误（区分大小写、多余空格）；② 配置后完整重启客户端；③ 检查网络是否能正常访问中转地址。
鼠标悬停会话，不显示删除按钮
排查：① 确认是悬停而非点击；② 更新Codex++至 v1.1.5 及以上版本。
网盘下载文件失败/速度慢
解决：切换网络环境，或前往GitHub项目页查看备用下载渠道。
Codex原版升级后，增强功能失效
解决：重新运行一次 Codex++ Manager 自检修复，再重启客户端即可。

十、工具使用边界总结
1. 适用范围
适配：主流 Windows、macOS 系统 + 官方正式版 Codex 桌面客户端
定位：纯增强启动器，依附原版程序运行，
不破解、不篡改、无广告
2. 不适用场景
无法单独脱离原版Codex运行
不支持移动端、网页版 Codex
不提供API接口搭建、密钥申请相关服务
3. 安全说明
项目完全开源，代码可公开查阅，仅做功能增强，不会收集用户对话、密钥等隐私数据。
