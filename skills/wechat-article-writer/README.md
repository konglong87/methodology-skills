# 微信公众号排版器

**丢一个 .md 文件进去，自动产出可复制到公众号编辑器的精美排版文章 + 全套配图。**

## 快速开始

### 1. 准备 Markdown 文章

```markdown
# 我的文章标题

## 一、开头

正文内容...

- 要点 1
- 要点 2

## 二、核心

**重点内容**——更多文字...
```

> 用 `一、` `二、` 中文编号分段效果最好，也支持 `##` Markdown 标题。

### 2. 一键生成

```bash
cd methodology-skills
node skills/wechat-article-writer/wechat-full.js 我的文章.md -o output/
```

可选参数：
- `--theme stripe` — 配图风格：`apple`（明亮，默认）`linear`（暗黑）`stripe`（人文）`muji`（侘寂）
- `--article-theme tech` — 文章排版：`tech` `product` `warm` `zen`（默认自动推断）
- `-o ./输出目录/` — 指定输出路径

### 3. 获取结果

```
output/
├── article-plain.html    ⭐ 用浏览器打开，全选复制，粘贴到公众号编辑器
├── article.html          图文混排预览（浏览器打开看效果）
├── 插入指南.md            配图上传位置对照表
└── screenshots/{theme}/
    └── wide/             宽屏配图（16:9，文章实际使用的）
```

### 4. 发布

1. 浏览器打开 `article-plain.html` → `Cmd+A` → `Cmd+C`
2. 粘贴到微信公众号编辑器
3. 上传 `screenshots/` 里的配图到公众号素材库
4. 看 `插入指南.md` 把图片插到对应位置
5. 预览 → 发布

## 输入格式自动识别

| 你写 | 自动识别为 |
|------|-----------|
| `一、标题` `二、标题` | 一级章节标题 |
| `1. 小节` `2. 小节` | 二级标题 |
| 普通段落 | 正文 |
| `- 要点` `· 要点` | 列表 |
| `> 引用` | 引用块 |
| `**强调**` | 加粗（主题色） |
| `快速回顾` `划重点` | 高亮块 |
| `---` | 分隔线 |

## 配图说明

每篇文章自动生成：

| 图片 | 位置 |
|------|------|
| 头图 | 标题下方 |
| 每章配图 | 每个章节后面（包含该章核心要点） |
| 文末引导图 | 文章末尾 |

同时产出竖长版（750×1334）和宽屏版（1200×675），文章默认用宽屏版。

## 常见问题

**Q: 生成的 HTML 粘贴到公众号后样式不对？**
A: 用 `article-plain.html`，不要用 `article.html`。`plain` 版已经把所有图片替换为占位框，粘贴后不会出现红叉。

**Q: 图片粘贴到公众号后丢失了？**
A: 图片必须先上传到微信公众号素材库，再手动插入。参考 `插入指南.md` 的对照表。

**Q: 可以只要排版不要配图吗？**
A: 加 `--no-screenshots` 参数跳过截图。

**Q: 支持纯文本文件吗？**
A: 支持。不需要 Markdown 格式，纯文本也会自动解析章节结构。
